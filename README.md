Task Tracker App 🚀

A full-stack Task Tracker web application built using MERN Stack (MongoDB, ExpressJS, ReactJS, NodeJS). This application allows multiple users to register, create projects, and manage their project tasks with full CRUD operations.


🌟 Features

- User Signup and Login with JWT Authentication
- Create / Read / Update / Delete Tasks
- Track task status (e.g., Pending, Completed)
- Responsive UI
- Secure password hashing (bcrypt)
- Realtime timestamps on creation and completion


🛠 Tech Stack

Frontend: ReactJS, Axios, Tailwind CSS  
Backend: NodeJS, ExpressJS  
Database: MongoDB with Mongoose  
Authentication: JWT
